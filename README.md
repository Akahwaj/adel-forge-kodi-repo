# Adel Forge Kodi Repo

Xenon-inspired Kodi repo/wizard installer optimized for Fire TV and Android TV.

## Features
- Adel Forge Wizard
- Fire TV optimization profiles
- Buffer/cache tuning
- Xenon-style layout
- Backup and restore guidance
- Third-party add-on manifest

## Install Flow
1. Install Kodi 21 Omega
2. Install the Adel Forge repository zip
3. Open Adel Forge Wizard
4. Apply Lite, Balanced, Premium, or Safe profile
5. Configure your preferred add-ons and services# adel-forge-kodi-repo
