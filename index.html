Install the Adel Forge Wizard

In Kodi File Manager, choose Install from zip and enter one of these short URLs directly — no need to browse:

  • Repository (recommended) — enables auto-updates for the wizard:
    https://akahwaj.github.io/adel-forge-kodi-repo/repo.zip
  • Wizard only — one-time install of the wizard add-on:
    https://akahwaj.github.io/adel-forge-kodi-repo/wizard.zip

Install Flow

  1. Install Kodi 21 Omega.
  2. Add this GitHub Pages URL as a source.
  3. Install the Adel Forge repository ZIP.
  4. Launch Adel Forge Wizard.
  5. Select Lite, Premium, Max, Sports, or Safe Mode.
